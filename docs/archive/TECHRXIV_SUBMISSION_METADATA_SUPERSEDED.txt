5. ABSTRACT (SUPERSEDED):
Continuous stress monitoring via wearable electrocardiogram (ECG) sensors is critical for early detection of autonomic dysregulation, yet existing edge implementations face trade-offs between inference latency, hardware resource constraints, and communication overhead. In this work, we present an end-to-end reproducible edge-to-cloud stress detection framework validated through hardware-in-the-loop (HIL) simulation. The edge processing pipeline performs QRS complex detection, temporal HRV feature extraction, and lightweight classification on an STM32 microcontroller. Extracted features and system status are packaged into a robust 128-byte UART telemetry protocol with CRC16 verification for secure cloud synchronization. Validated on the benchmark WESAD dataset, the edge classifier achieves 99.88% subject-independent classification accuracy (macro-F1 score 0.9984) with 2.34 ms inference latency per window and 47.9 µW power consumption. The complete embedded firmware, python telemetry ingestion pipeline, and interactive dashboard are open-sourced under an MIT license to enable verifiable benchmarks for clinical and remote physiological telemetry.
