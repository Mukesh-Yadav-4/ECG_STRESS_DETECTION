3. Detailed Phase Breakdown

Phase 1: Clinical Signal Processing & Data Extraction COMPLETED

  • Extracted 700 Hz Lead-II ECG and labels across 15 WESAD subjects into standardized .mat files.
  • Implemented baseline wander & noise rejection: 4th-order Butterworth (0.5–40 Hz) and 50 Hz notch filter.
  • Extracted 8 Core Autonomic HRV Metrics: MeanHR, RMSSD, SDNN, pNN50, MeanRR, RR_CV, RR_IQR, HR_IQR.

Phase 2: Multi-Model Machine Learning Benchmark COMPLETED

  • Applied zero-leakage subject-specific baseline normalization: Δx = (x - μbaseline) / max(|μbaseline|, ε).
  • 15-Fold Leave-One-Subject-Out (LOSO) cross-validation results: Logistic Regression (92.13% Acc, 88.29% F1 — Top Performer), MLP Neural Net (91.69% Acc, 87.87% F1), SVM RBF (91.46% Acc, 0.9524 ROC-AUC — Highest AUC).

Phase 3: STM32 C Firmware Core COMPLETED

  • CMSIS-DSP Biquad IIR filter (ecg_dsp_filter.c) matching exact MATLAB design.
  • 20-byte binary telemetry frame (Sync 0xAA 0x55, Version, Flags, SeqID, Timestamp, Raw ECG, Filt ECG, CRC-16-CCITT).
  • Hardware-free verification harness (main_bench.c) validated with 100% CRC integrity.

Phase 4: PC Telemetry Receiver & Stream Ingestion COMPLETED

  • Thread-safe non-blocking Python receiver (stm32_telemetry_receiver.py) with auto-sync and CRC checking.
  • End-to-end stream simulator (simulate_stm32_stream.py) verified: 7,000 frames streamed with 0 drops and 100% stress detection on S10.

Phase 5: Streamlit Live Telemetry Dashboard COMPLETED

  • Added Tab 1: STM32G474 IoMT Hardware Telemetry with dual-mode virtual and physical COM port support.
  • Live rolling Plotly strip-chart (Raw vs. Filtered), 6 HRV autonomic meters, and calibrated stress dial (τ=0.35).

Phase 6: Physical STM32 Deployment & AD8232 Sensor NEXT STEP

  • Configure STM32CubeIDE: TIM2 trigger @ 700 Hz, ADC1 DMA circular mode, USART2 Virtual COM Port DMA.
  • Wire AD8232: 3.3V, GND, OUTPUT → PA0, LO+/LO- → PB0/PB1.

Phase 7: Secure IoMT Cryptographic Layer PLANNED (PHASE 2)

  • Deploy Hyperchaotic map & geometric transformation encryption on STM32 telemetry frames.
